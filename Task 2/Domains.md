| Домен                             | Назначение                                                                       | Аргументация                                                                                               |
| --------------------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Medical Domain (FutureMedic)                | Регистрация пациентов, приёмы, анализы, расписания, заключения                   | Содержит бизнес-логику медицинских процессов. Независим от финансов и аналитики по логике.                 |
| FinTech Domain              | Платежи, выставление счетов, кредитование, фин. отчётность, расчёты с пациентами | Отвечает за финансы, связан с медицинским доменом через события и API (например, оплата приёма).           |
| Data Integration Domain (ESB) | Очистка, нормализация, маршрутизация событий/данных в LakeHouse                  | Позволяет разделить продакшн-логику и аналитическую подготовку. Выделяется как самостоятельный шлюз.       |
| Data LakeHouse Domain         | Хранилище медицинских и финансовых данных, BI, отчёты, ML, аналитика             | Хранит и обрабатывает данные без логики бизнес-процессов. Не зависит от Medical/Financial Domain напрямую. |
